# SBSeg 2027

Site do XXVII Simpósio Brasileiro de Cibersegurança (SBSeg 2027), publicado em https://sbseg-sbc.github.io/2027/.

Cada edição do SBSeg tem um repositório próprio na organização `sbseg-sbc`. O site principal, https://sbseg-sbc.github.io/, mapeia todas as edições.

## Publicação

GitHub Pages, ramo `main`, pasta raiz (Settings > Pages > Deploy from a branch).

## Regra de ouro dos links

O site é servido sob o prefixo `/2027/`. Use sempre caminhos relativos (`assets/estilo.css`, `programacao.html`). Um caminho começando com `/` aponta para a raiz da organização e quebra. Para voltar ao site principal, use `../`.
